# 🎮 2048 Game

¡Bienvenido al clásico juego 2048 implementado con HTML, CSS y JavaScript puro! Este proyecto es una versión moderna y responsive del popular juego de rompecabezas numérico.

## 🎯 Características

- Interfaz de usuario limpia y responsiva
- Sistema de puntuación con récord personal
- Tema claro/oscuro con preferencia guardada
- Compatible con teclado y pantallas táctiles
- Diseño moderno con animaciones suaves
- Totalmente en español

## 🎮 Cómo jugar

1. Usa las **teclas de flecha** (↑, →, ↓, ←) en tu teclado o desliza el dedo en dispositivos táctiles
2. Las fichas con el mismo número se combinan cuando chocan
3. Intenta alcanzar la ficha 2048
4. El juego termina cuando no hay más movimientos posibles

## 🚀 Instalación

1. Clona este repositorio:

   ```bash
   git clone https://github.com/NachoLedesma33/Game-2048.git
   ```

2. Abre el archivo `index.html` en tu navegador web

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3 (con variables CSS para los temas)
- JavaScript Vanilla (ES6+)
- Google Fonts (Poppins)

## 🎨 Personalización

Puedes cambiar fácilmente los colores y estilos modificando las variables CSS en el archivo `styles.css`.

## 📱 Soporte para móviles

El juego está completamente optimizado para dispositivos móviles con controles táctiles intuitivos.
